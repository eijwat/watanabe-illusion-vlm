# Pinned to match the DGX Spark environment that produced the existing
# Qwen2.5-VL-32B N=60 results. Reproducibility is the goal: when running
# Qwen3-VL-32B on the A100, the *only* intended variables are the machine
# (DGX Spark <-> A100) and the model (Qwen2.5-VL <-> Qwen3-VL).
# Library versions are held constant.
#
# Notes
# -----
# - transformers==5.6.2 : exact version used on DGX Spark for N=60 v2.
#                         Includes native support for both Qwen2.5-VL
#                         (Qwen2_5_VLForConditionalGeneration) and
#                         Qwen3-VL (Qwen3VLForConditionalGeneration).
# - qwen-vl-utils>=0.0.14 : required by Qwen3-VL for the new
#                           process_vision_info(image_patch_size=...)
#                           signature.
# - flash-attn is intentionally omitted. SDPA in PyTorch 2.10 + NGC 25.11
#   is sufficient for N=60 behavioural runs on this stimulus size. Adding
#   flash-attn complicates the build and is not required for replication.
# - bitsandbytes / sentencepiece / tiktoken are kept for compatibility
#   with the rest of the project's scripts (LLaVA-NeXT 34B/72B loaders),
#   even though the Qwen3-VL replication itself does not need them.
# =============================================================================
